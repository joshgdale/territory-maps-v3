# What’s New announcements — 2026-08-06

## Intent

Notify every congregation of newly released features via a **non-dismissable** amber banner on the dashboard, titled **What’s New**. Entries are global (not congregation-scoped) and remain visible for **30 days** after `addedAt`.

## Schema

Evolve migration `1786021803000_create_whats_news_table` creates:

| Column | Notes |
|--------|--------|
| id | nanoid |
| content | text (multi-line) |
| addedAt | dateTime; set to now on create |

## Behaviour

- Dashboard loads active rows (`addedAt` within last 30 days), newest first
- Banner has no dismiss control; hidden only when no active items
- Ace: `node ace whats-new:create` (interactive multi-line) or `--content="…"` (`\n` for line breaks)
