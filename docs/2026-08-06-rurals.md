# Rurals feature — 2026-08-06

## Intent

Add first-class **Rural** locations on maps (geo points with What3Words), with street-like completion checkoffs, admin edit, public view (when present), and a one-time CSV ingest Ace command.

## Schema

After Address→DoNotCall evolve dropped the unused Prisma `Rural` stub, evolve migration `1786019366171_recreate_rurals_table` recreates:

| Column | Notes |
|--------|--------|
| id | nanoid |
| mapId | FK → Map, cascade |
| latitude / longitude | doubles |
| what3words | normalized (no leading `/`) |
| description | text |
| isComplete | boolean, default false |

## Behaviour

- Map detail: Rurals checklist with faded lat/lon/w3w meta, logo buttons (w3w / Google / Apple), + edit panel
- Public page: Rurals card **only if any**; same UI without edit
- Bring map IN: clear rural `isComplete` alongside streets
- Ingest: `node ace rural:ingest ./file.csv --congregation=NUMBER` (optional `--dry-run`)

CSV headers: `Latitude`, `Longitude`, `What3Words`, `Map` (map code), `Description`
