# Coolify deploy notes — 2026-08-06

Hosting Territory Maps v3 behind Coolify (Traefik/Caddy).

## Proxy / rate limiting

Coolify is the reverse proxy hop — no extra proxy needed.

Adonis trusts private-network proxies via `trustProxy: proxyAddr.compile(['loopback', 'uniquelocal'])` in `config/app.ts`, so:

- `request.ip()` sees the real client (login rate limits work)
- `X-Forwarded-Proto` is trusted (HTTPS / secure cookies)

## Env for Coolify

| Key | Coolify value |
|-----|----------------|
| `HOST` | `0.0.0.0` |
| `PORT` | `3333` (must match Coolify **Ports Exposes** + healthcheck port) |
| `APP_URL` | Public `https://your-domain` (no trailing slash) |
| `NODE_ENV` | `production` |
| `LIMITER_STORE` | `database` if >1 replica; `memory` OK for a single container |
| `SESSION_DRIVER` | `cookie` (or `database` if you prefer shared sessions) |
| `GOTENBERG_URL` | Internal Coolify service URL, e.g. `http://gotenberg:3000` |

Share links and PDFs use `APP_URL` — set it to the public HTTPS origin.

**Port:** Adonis binds to `$PORT` at runtime. Coolify **Ports Exposes**, healthcheck port, and the `PORT` env must all be the same value (default `3333`).
